শর্টকাট (Mac হলে Ctrl-এর জায়গায় Cmd)
-----------------------------------------------------
P   = Ctrl + P          ফাইলের নাম লিখে ফাইল খোলা
O   = Ctrl + Shift + O  ফাইলের সব function-এর list, click করলে সেখানে যায়
F   = Ctrl + F          ফাইলের ভেতরে লেখা খোঁজা
Ctrl + Shift + F        পুরো প্রজেক্টে খোঁজা
Ctrl + G                line number দিয়ে সেই line-এ যাওয়া
Ctrl + click            কোনো নামের উপর -> সরাসরি সেই ফাইলে যায়
Ctrl + Tab              খোলা ফাইলগুলোর মধ্যে যাওয়া

মনে রাখো:
- .tsx ফাইলে O চাপলে function আসে, কিন্তু button-এর লেখা (যেমন "Mark resolved")
  আসে না। ওগুলোর জন্য F ব্যবহার করবে।
- F-এর box-এ আগে থেকে কোনো শব্দ বসে থাকলে, box-এর ভেতরে Ctrl + A চেপে তারপর লেখো।
- F-এর box সবসময় এক line-এর মতো ছোট থাকা উচিত। লম্বা হয়ে গেলে (Ctrl/Shift + Enter
  চাপলে হয়) কিছুই খুঁজে পাবে না -> box-এ Ctrl + A -> Backspace -> আবার হাতে টাইপ করো।
- এগুলো শুধু খোঁজা, কোড বদলায় না। ভুল করে কোডে কিছু টাইপ হলে Ctrl + Z চাপো,
  আর Ctrl + S চাপবে না। tab-এর নামের পাশে সাদা ● দেখালে বুঝবে কিছু বদলেছে।

সাবধান — একই রকম নাম
-----------------------------------------------------
- P-তে "dashboard" লিখলে কয়েকটা আসবে:
    Dashboard.tsx           (page, frontend)        <- এটা তোমার
    dashboardService.ts     (service, frontend)     <- এটা তোমার
    dashboard.py            (backend)               <- এটা তোমার
    AdminDashboard.tsx      (admin page)            <- এটা তোমার না
- "auth.py" লিখলে দুটো আসবে:
    backend/routers/auth.py  -> change_password, logout (এটা লাগবে)
    backend/auth.py          -> get_current_user, hash_password
- "schemas" লিখলে দুটো আসবে:
    client/src/lib/schemas.ts  (frontend form-এর নিয়ম, Zod)
    backend/schemas.py         (backend-এর নিয়ম, Pydantic)
- নামের নিচে ছোট করে path দেখায় (যেমন backend/routers)। ওটা দেখে নিশ্চিত হবে।

ভাগ ৩ — মনময়ের অংশের API (মোট ৬টা)
=====================================================
প্রতিটা API-এর ৩টা জায়গা: কে call করে (page) -> কোথায় লেখা (service)
-> backend-এর কোন function। ফাইল খুলে Ctrl + G দিয়ে line number-এ যাও।

API 1 — Item-এর list (Browse, My Posts)
-----------------------------------------------------
GET /api/items?search=...&type=...&category=...&location=...&status=...&mine=...&sort=...
কাজ: filter আর search মিলিয়ে item আনে। Browse, My Posts আর Resolved
     (আফিফার) — তিনটাই এই একটা API ব্যবহার করে।

  কে call করে :  Browse.tsx                          line 59
                 MyPosts.tsx  (mine: true)           line 23
  Service     :  itemService.ts   -> list            line 21
  Backend     :  items.py         -> list_items()    line 75

API 2 — Post-এর status বদলানো (Mark resolved)
-----------------------------------------------------
PATCH /api/items/{id}/status       body: {"status": "resolved"}
কাজ: open / pending / resolved করা। resolved আবার খোলা যায় না (409)।
     অন্যের post হলে 403।

  কে call করে :  MyPosts.tsx                         line 36
  Service     :  itemService.ts   -> setStatus       line 33
  Backend     :  items.py         -> set_item_status()  line 227

API 3 — Post withdraw (delete)
-----------------------------------------------------
DELETE /api/items/{id}
কাজ: soft delete — row মোছে না, শুধু is_removed = True।
     অন্যের post হলে 403।

  কে call করে :  MyPosts.tsx                         line 48
  Service     :  itemService.ts   -> remove          line 36
  Backend     :  items.py         -> delete_item()   line 260

API 4 — Dashboard-এর summary (Dashboard, Profile)
-----------------------------------------------------
GET /api/dashboard
কাজ: ৪টা সংখ্যা (counts), শেষ ৩টা post (recent_items),
     শেষ ৫টা notification (recent_activity)।

  কে call করে :  Dashboard.tsx                       line 16
                 Profile.tsx                         line 21
  Service     :  dashboardService.ts -> get          line 6
  Backend     :  dashboard.py     -> dashboard()     line 23

API 5 — Password বদলানো
-----------------------------------------------------
POST /api/auth/change-password
     body: {"current_password": "...", "new_password": "..."}
কাজ: পুরনো password মিলিয়ে দেখে (না মিললে 400), নতুনটা hash করে save।

  কে call করে :  Profile.tsx                         line 46
  Service     :  authService.ts   -> changePassword  line 45
  Backend     :  auth.py (routers) -> change_password()  line 361

API 6 — Sign out
-----------------------------------------------------
POST /api/auth/logout
কাজ: login cookie মুছে দেয়।

  কে call করে :  Profile.tsx (logout())              line 126
                 -> AuthContext.tsx                  line 77
  Service     :  authService.ts   -> logout          line 29
  Backend     :  auth.py (routers) -> logout()       line 199

শুধু link, API তোমার না (জিজ্ঞেস করলে বলবে কোথায় নিয়ে যায়)
-----------------------------------------------------
- Edit button (My Posts)       -> /items/{id}/edit, save করলে PUT /api/items/{id}
                                  (items.py -> update_item(), line 205)
- Report an item / Report lost item / Report found item
                               -> নতুন post-এর form (Feature 1)
- Dashboard-এর Smart match card, See all, Review match
                               -> আফিফার GET /api/matches
- Dashboard-এর Recent activity  -> notification, আফিফার অংশ

ভাইভায় API দেখানোর সহজ ক্রম
-----------------------------------------------------

-> Ctrl + G দিয়ে line number।
